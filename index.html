공공데이터포털 열기
  1. 1

    공식 API 두 건 활용신청

    공공데이터포털에 로그인한 뒤 아래 서비스에서 활용신청을 누르고, 마이페이지에서 승인 상태를 확인합니다.

    의약품 제품 허가정보 품목 목록·상세·주성분 정보 · 실시간 갱신 DrugPrdtPrmsnInfoService07
    신청 페이지
    의약품 생산·수입실적현황 최근 연도 생산·수입금액과 실적연도 · 연간 갱신 MdcinPrdctnImportAcmsltService02
    신청 페이지
  2. 2

    일반 인증키 확인

    승인된 활용신청 상세 화면에서 일반 인증키(Decoding)를 확인합니다. 앞뒤 공백 없이 키 값만 사용합니다.

    보안 주의 인증키는 채팅, 화면 캡처, 소스코드, 커밋 기록에 남기지 마세요. 이 페이지도 키의 등록 여부만 표시합니다.
  3. 3

    Vercel 환경변수 등록

    Vercel 프로젝트의 Settings → Environment Variables에서 아래 이름으로 추가하고, 값에는 일반 인증키를 입력합니다.

    권장 환경변수명 MFDS_OPENAPI_SERVICE_KEY
    • Production은 반드시 선택합니다.
    • 미리보기 배포에서도 확인하려면 Preview도 선택합니다.
    • DATA_GO_KR_SERVICE_KEY도 호환되지만 위 권장 이름을 우선 사용합니다.
    Vercel 환경변수 공식 문서
  4. 4

    저장 후 새로 배포

    환경변수는 기존 배포에 소급 적용되지 않습니다. 저장한 다음 Deployments에서 최신 배포를 Redeploy하거나 main에 새 커밋을 푸시합니다.

  5. 5

    대시보드에서 감지 상태 확인

    새 배포 주소에서 환경설정의 연결 현황으로 돌아가 새로고침합니다. 인증키가 등록되고 활성 공식 API가 2 / 2개로 표시되면 서버가 환경변수를 감지한 상태입니다.

    이 상태는 환경변수 등록 여부를 확인합니다. 인증키 승인·유효성, 호출 한도, 실제 응답은 검색 요청 시 공공데이터포털 응답으로 최종 확인됩니다.

인증키 오류 또는 401 응답일반 인증키(Decoding)를 사용했는지, 두 API의 활용신청이 승인됐는지, 키 앞뒤에 공백이 없는지 확인합니다.
요청 한도 또는 429 응답공공데이터포털 마이페이지에서 일일 트래픽과 활용계정 상태를 확인합니다.
시간 초과 또는 5xx 응답잠시 뒤 재시도하고, 공공데이터포털 서비스 상태와 Vercel Function 로그를 확인합니다.

자주 묻는 내용

왜 인증키를 이 화면에서 직접 입력하지 않나요?

브라우저에 입력한 키는 개발자 도구나 네트워크 기록을 통해 노출될 수 있습니다. 서버 환경변수에 저장해야 API 호출에만 사용되고 화면에는 원문이 전달되지 않습니다.

API 두 건을 모두 신청해야 하나요?

허가정보 검색에는 제품 허가정보 API가 필요하고, 생산·수입실적을 함께 보려면 생산·수입실적현황 API도 필요합니다. 현재 대시보드 기능 전체를 사용하려면 두 건 모두 신청하는 것이 맞습니다.

환경변수를 바꿨는데 이전 배포 주소에는 왜 반영되지 않나요?

Vercel 환경변수 변경은 새로 생성되는 배포부터 적용됩니다. 최신 커밋을 다시 배포한 뒤 새 배포 또는 운영 도메인에서 확인해야 합니다.
